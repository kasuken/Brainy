# Export to a Markdown / Obsidian-compatible vault
<!-- labels: enhancement,priority: P2,area: trust,area: platform -->

## Problem

Data portability today is a versioned JSON export. It is complete and it round-trips into Brainy, but it is machine-readable only — a user cannot open it, read it, or take it anywhere else. Version 6.0.0 shipped privacy, terms and AI-transparency pages that make explicit promises about the user's data; an export nobody can actually use elsewhere makes "no lock-in" a weaker claim than it should be.

## Scope

- Export as a zip of folders and Markdown files, organised by PARA category.
- YAML front matter carrying tags, dates, status and provenance.
- `[[wiki links]]` for note relationships so the vault opens correctly in Obsidian.
- Note images exported alongside and correctly referenced.
- Runs as a background job for large accounts with a download link when complete.

## Guardrails

- Complements the JSON export; does not replace it. JSON stays the round-trip format.
- Same user scoping and rate limiting as the existing export.
- Never includes credentials, BYOK keys or analytics identifiers.
- Deterministic, filesystem-safe filenames; collisions resolved, not overwritten.

## Acceptance criteria

- [ ] The exported vault opens in Obsidian with links and tags intact.
- [ ] Images resolve.
- [ ] A large account exports without timing out the request.
- [ ] No secret material appears anywhere in the archive.
