# Wire the existing IAiAssistant surface into Inbox and capture
<!-- labels: enhancement,priority: P1,area: workflow,area: capture -->

## Problem

`IAiAssistant` exposes five operations. Only three are ever called — `SummarizeAsync`, `ExtractActionItemsAsync` (from `ActionItemService`) and `GenerateOutputAsync` (from `OutputAiGenerationDialog`). Two are fully implemented, prompt-engineered, and **completely unreferenced**:

- `SuggestParaClassificationAsync`
- `DetectDuplicatesAsync`

Meanwhile `InboxSuggestionsService` — the thing that actually suggests where a note belongs — is a hardcoded keyword heuristic. It scores notes against literal string arrays: `"task", "action", "deadline", "by ", "due"` for Projects, `"article", "reference", "research"` for Resources, and so on.

The AI classifier you already built and pay to maintain is sitting next to a keyword list that does the same job worse.

## Scope

- Use `SuggestParaClassificationAsync` in the Inbox processing flow (`ProcessNoteDialog`, `BulkProcessDialog`), with the keyword heuristic as the fallback when AI is unavailable, disabled, or below a confidence threshold.
- Use `DetectDuplicatesAsync` on capture — both `ShareCaptureService` and quick capture — to complement the exact-match duplicate detection added in 6.0.0.
- Show confidence and let the user accept or reject, per the acceptance criteria of #15.
- Persist provider, model, prompt version and the original generated value separately from user edits, as `AGENTS.md` requires.

## Existing work

This closes the implementation gap behind #15 (Suggest PARA Classification) and part of #14 (Generate Note Summary) without new AI infrastructure.

## Guardrails

- AI stays opt-in and entitlement-gated; when it is off, the current heuristic behaviour is unchanged.
- Suggestions are never auto-applied. The user decides.
- No note content in analytics events — follow the pattern in `SearchService`, which tracks that a search happened but never the term.

## Acceptance criteria

- [ ] Inbox processing shows an AI-suggested category with a confidence indicator when AI is enabled.
- [ ] With AI disabled, the keyword heuristic behaves exactly as it does today.
- [ ] Near-duplicate captures are flagged with a link to the existing note.
- [ ] Accepted suggestions retain provenance distinguishable from user edits.
- [ ] Tests cover the fallback path, the confidence threshold, and user isolation.
