# Publish an ICS calendar feed for deadlines
<!-- labels: enhancement,priority: P1,area: workflow,area: platform -->

## Problem

`ICalendarService` and `TaskCalendarPage` render deadlines inside Brainy only. A user's actual calendar — Outlook, Google, Apple — knows nothing about their Brainy due dates, so Brainy has to be opened to be useful. For a planning tool, that is the wrong direction of information flow.

## Scope

- Authenticated ICS feed endpoint exposing tasks with due dates, project deadlines and goal milestones.
- Per-user revocable feed token, since calendar clients cannot perform an interactive login.
- Filters on the subscription URL, reusing `CalendarFilterDto` where it fits.
- Sensible `VEVENT` mapping: all-day events for user-calendar dates, honouring the existing rule that due dates are user-calendar dates while audit timestamps stay UTC.
- Documentation on the help surface for subscribing in the major clients.

## Guardrails

- The feed token grants read-only access to calendar fields only, never full account access.
- Tokens are revocable and regenerable, and the current token is never exposed in analytics or logs.
- Rate-limit the endpoint; calendar clients poll aggressively.
- Archived items are excluded by default, consistent with every other active workflow.

## Acceptance criteria

- [ ] Subscribing to the URL in Outlook and Google shows current deadlines.
- [ ] Revoking the token breaks the subscription immediately.
- [ ] One user's token never returns another user's events.
- [ ] Timezone handling is correct for a user whose timezone differs from the server's.
