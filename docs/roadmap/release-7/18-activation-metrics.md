# Compute activation funnel metrics on the analytics dashboard
<!-- labels: enhancement,priority: P1,area: onboarding,area: commercial -->

## Problem

Version 6.0.0 shipped a consent-gated analytics pipeline, a public event data dictionary and `AnalyticsDashboardPage`. The events are being collected. But #292's success measures — *"more people complete a first capture-to-focus loop"*, *"more captured items are reused in active work or outputs"*, *"search and resurfacing lead to useful follow-on actions"* — are not computed anywhere.

That matters immediately, because #293 asks for a go/no-go decision on Starter Mode, Capture Anywhere, semantic retrieval and pricing. Without funnel metrics, that decision rests on 10-15 moderated sessions and nothing else. The instrumentation to back it up already exists and is unused.

## Scope

- Activation funnel: registered → first capture → first classify → first task → first current focus → first output.
- Time-to-activation distribution and drop-off per step.
- Knowledge reuse rate: share of captured items later referenced in a task, project or output.
- Retrieval effectiveness using the `SearchSubmitted` and `SearchZeroResult` events already tracked, plus follow-on action rate.
- Weekly review and Inbox processing adherence.
- Render on the existing `AnalyticsDashboardPage`; export as CSV for the #293 analysis.

## Guardrails

- Aggregate only. No dashboard view may expose an individual user's content.
- Respect the existing consent gate — non-consenting users are absent from the data, and the numbers must say so rather than quietly undercounting.
- Do not add new event types that capture note content, search terms or anything the published data dictionary does not already cover. If a metric needs a new event, update the public dictionary in the same change.

## Acceptance criteria

- [ ] The activation funnel renders with per-step conversion and drop-off.
- [ ] Reuse rate and retrieval effectiveness are computed from existing events.
- [ ] Consent-excluded users are reported as a known denominator gap, not silently omitted.
- [ ] Any new event appears in the public data dictionary.
- [ ] Metrics are exportable for the #293 discovery work.
