# Extend global search into a command palette
<!-- labels: enhancement,priority: P2,area: workflow -->

## Problem

`GlobalSearchBar` already has keyboard activation (`OpenFromKeyboardAsync`), grouped results and arrow-key navigation. It finds *records*. It cannot perform *actions* — a user who wants to create a task, jump to the Week page or set a current focus has to navigate there with the mouse.

For a keyboard-driven execution surface like Today, that is the one missing affordance.

## Scope

- Extend the existing search overlay with a command mode rather than building a second component.
- Navigation commands for every top-level surface.
- Creation commands: new note, task, project, idea, output.
- Contextual actions: set current focus, start weekly review, process Inbox.
- Recent and frequent commands ranked first.
- Discoverable shortcut hint and a shortcut reference in the existing `PageHelpWizardDialog`.

## Guardrails

- Do not regress existing search behaviour or its keyboard navigation.
- Commands respect entitlements — a Starter user at their project limit sees the normal upgrade path, not a silent failure.
- Accessible: full keyboard operation, correct ARIA roles, visible focus.

## Acceptance criteria

- [ ] The palette opens from the keyboard on every authenticated page.
- [ ] Records and commands are distinguishable in results.
- [ ] Every command is reachable without a mouse.
- [ ] Existing search behaviour is unchanged when typing a plain query.
